# math_html_making

중학교 수학 `자료와 가능성` 개념 정리, 퀴즈, 몬티홀 게임을 하나의 오프라인 HTML 파일로 구성한 프로젝트입니다.

## 실행

`자료와-가능성-통합본.html` 파일을 브라우저에서 열면 됩니다. 별도의 서버, 데이터베이스, 인터넷 연결이 필요하지 않습니다.

## 구성

- `정리` 탭: 자료와 가능성의 핵심 개념과 도표를 확인합니다.
- `퀴즈` 탭: 빈칸, 객관식, 상자그림 드래그 활동을 진행하고 정답을 확인합니다.
- `게임` 탭: 몬티홀 미니게임을 실행합니다.

## 구현 방식

- 원본 PDF의 `자료와 가능성` 영역을 HTML, CSS, SVG로 재구성했습니다.
- 줄기와 잎 그림을 수정하면 포커스를 벗어날 때 도수분포표와 히스토그램, 도수분포다각형이 함께 갱신됩니다.
- 퀴즈는 원문 레이아웃을 유지하기 위해 정답 텍스트 위에 빈칸을 오버레이하는 방식으로 구현했습니다.
- 모든 이미지, 수식 글꼴, 몬티홀 게임을 Base64 데이터로 HTML 안에 내장했습니다.

## 단일 파일

통합본은 외부 PNG, 글꼴, 게임 HTML 파일을 참조하지 않습니다. 파일 하나만 복사하거나 배포해도 동일하게 실행됩니다.
