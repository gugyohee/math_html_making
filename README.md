# math_html_making

중학교 수학 `자료와 가능성` 단원을 위한 단일 HTML 학습 활동지입니다. 비상교육 자료의 마지막 페이지에 있는 `자료와 가능성` 영역을 바탕으로, **정리 → 퀴즈 → 게임** 흐름의 웹 활동으로 재구성했습니다.

- 결과 파일: `자료와-가능성-통합본.html`
- 제작일: 2026-09-14
- 실행 환경: 최신 Chrome, Edge, Firefox 등 데스크톱/모바일 브라우저
- 서버·DB·로그인·인터넷: 필요 없음

## 실행 방법

`자료와-가능성-통합본.html` 파일 하나를 브라우저에서 열면 됩니다. 파일을 다른 PC, USB, LMS 등에 복사해도 동일하게 실행됩니다.

## 설계 목표

- 원본 자료의 핵심 구조와 시각적 흐름을 유지한다.
- 단순 이미지 캡처가 아니라, 수정 가능한 HTML 텍스트·CSS·SVG 도표로 구성한다.
- 원문 문장 폭과 레이아웃을 유지한 상태에서 빈칸을 오버레이한다.
- 정리한 내용을 바로 퀴즈와 게임으로 연결한다.
- 학생 입력은 즉시 채점하지 않고, 필요할 때 `정답 확인`으로 피드백한다.

## 탭 구성

### 1. 정리 탭

원본 `자료와 가능성`의 내용을 한 화면에서 복습하는 탭입니다.

#### 개념 및 도표

- **대푯값**: 중앙값, 최빈값의 정의와 원본 삽화
- **줄기와 잎 그림**: 10대, 20대, 30대, 40대 자료를 입력·관찰하는 표
- **도수분포표**: 계급, 도수, 계급의 크기 10세를 시각적으로 표시
- **히스토그램과 도수분포다각형**: 막대그래프와 다각형을 함께 표시
- **상대도수와 그 그래프**: 상대도수 식, 세로축, A/B 그래프 예시
- **확률**: 확률의 정의, 확률의 성질, 확률의 계산
- **산포도**: 편차, 분산, 표준편차의 관계
- **사분위수와 상자그림**: 최솟값, 제1사분위수, 중앙값, 제3사분위수, 최댓값
- **산점도와 상관관계**: 양의 상관관계, 음의 상관관계, 상관관계 없음

#### 줄기와 잎 그림 연동 UX

줄기와 잎 그림은 단순한 예시가 아니라 편집 가능한 입력 영역입니다.

- 잎에는 `0~9` 숫자만 입력할 수 있습니다.
- 문자, 기호 등 숫자가 아닌 입력은 차단됩니다.
- 붙여넣기할 때도 숫자만 남습니다.
- 입력 중에는 도수분포표와 그래프가 바뀌지 않습니다.
- `Enter`를 누르거나 입력칸 밖을 클릭해 포커스가 해제되면 다음 작업이 이루어집니다.
  1. 입력 숫자를 공백으로 정리해 표시합니다.
  2. 잎이 오름차순인지 검사합니다.
  3. 오름차순이 아니라면 `잎에는 수가 크기순으로 나열되어야 합니다.` 경고를 빨간색으로 표시합니다.
  4. 입력값을 기준으로 도수분포표, 합계, 히스토그램, 도수분포다각형을 갱신합니다.
- 도수분포다각형의 첫 점은 원점이 아니라 `0~10` 구간의 가운데를 기준으로 표현합니다.

#### 시각 구현

- 개념명은 주황색 둥근 라벨로 표시합니다.
- 표·수식·정의는 HTML 텍스트로 구성해 향후 빈칸/문항 편집이 가능합니다.
- 히스토그램, 도수분포다각형, 상대도수 그래프, 상자그림, 산점도는 SVG/CSS로 구성했습니다.
- 도수분포표의 계급·도수 표시, 선택 계급 강조, 계급의 크기 설명을 원본 구조에 맞춰 배치했습니다.
- 수식·숫자에는 추출한 `EHsang` 계열 글꼴을 사용하고, 일반 한글에는 둥근 한글 글꼴을 사용합니다.

### 2. 퀴즈 탭

정리 탭의 내용을 복제해 사용하되, 정답 텍스트를 직접 지우지 않고 **원문 위에 물음표 네모칸을 덧씌우는 방식**으로 만들었습니다.

이 방식의 장점은 다음과 같습니다.

- 정리 탭과 퀴즈 탭의 문장 줄바꿈·위치·도표 구조가 동일합니다.
- 원문 텍스트는 HTML에 남아 있어 정답 비교가 가능합니다.
- 답을 다시 수정해도 원래 레이아웃이 흔들리지 않습니다.

#### 공통 빈칸 UX

- 모든 빈칸은 흰 배경, 검은 테두리, 둥근 모서리, `?` 표시로 통일했습니다.
- 빈칸을 클릭하면 해당 개념이나 도표를 확대하는 오버레이가 열립니다.
- 답을 입력하거나 보기를 선택한 후 `확인`을 누르면 원래 빈칸에 입력값이 표시됩니다.
- 입력값은 채점 후에도 다시 클릭해 수정할 수 있습니다.
- 텍스트 입력형 오버레이에서는 `Enter`가 `확인`과 동일하게 동작합니다.

#### 중앙값 빈칸

- 대푯값 정의의 `중앙값` 단어를 빈칸으로 처리합니다.
- 클릭 시 `중앙값`부터 `자료의 중앙에 위치한 값`까지의 문장을 크게 보여 줍니다.
- 확대 화면의 입력칸에 답을 쓰고 `확인` 또는 `Enter`를 누르면 본문의 빈칸에 반영됩니다.

#### 도수분포표 빈칸

- 퀴즈 본문에서는 원래의 `계급`, `도수` 위치에 각각 물음표 네모칸을 표시합니다.
- 네모칸을 클릭하면 도수분포표 전체와 계급·도수 괄호 표시가 오버레이로 열립니다.
- 오버레이에서 좌우 입력칸에 직접 답을 입력합니다.
- 입력칸의 크기와 형태는 중앙값 입력 UX와 통일했습니다.

#### 상자그림 드래그 퀴즈

- 퀴즈 본문에서는 최솟값부터 최댓값까지의 다섯 위치에 물음표 네모칸을 표시합니다.
- 아무 빈칸이나 클릭하면 상자그림 전체가 오버레이로 열립니다.
- 다음 보기 카드를 드래그해 각 위치에 배치합니다.
  - 최솟값
  - 제1사분위수
  - 중앙값
  - 제3사분위수
  - 최댓값
- 보기 카드는 오버레이를 열 때마다 무작위 순서로 섞입니다.
- 이미 카드가 놓인 위치에 다른 카드를 놓으면 이전 카드는 다시 보기로 돌아갑니다.
- `확인`을 누르면 배치 결과가 본문의 다섯 빈칸에 반영됩니다.

#### 확률의 계산 객관식

- 확률의 계산 `(1)`의 `p＋q`, `(2)`의 `p×q` 자리를 각각 빈칸으로 처리합니다.
- 빈칸을 클릭하면 해당 식 전체가 오버레이로 열립니다.
  - `(1)`: 사건 A 또는 사건 B가 일어날 확률
  - `(2)`: 사건 A와 사건 B가 동시에 일어날 확률
- 두 문제 모두 다음 네 보기 중 하나를 고릅니다.
  - ① `p＋q`
  - ② `p−q`
  - ③ `p×q`
  - ④ `p÷q`
- 선택한 보기는 `확인` 또는 `Enter` 후 본문의 빈칸에 반영됩니다.

#### 정답 확인 UX

퀴즈 탭 하단의 `정답 확인` 버튼이 현재 입력값을 한꺼번에 검사합니다.

- 정답이면 글자와 네모칸 테두리를 **파란색**으로 표시합니다.
- 오답이면 글자와 네모칸 테두리를 **빨간색**으로 표시합니다.
- 아직 답하지 않은 `?` 빈칸은 색을 바꾸지 않습니다.
- 답을 다시 수정하면 기존 색 피드백은 사라지고, 다시 확인할 수 있습니다.
- 모든 빈칸이 정답이면 버튼 문구가 `참 잘했어요!`로 바뀝니다.
- 동시에 화면 상단에 `참 잘했어요! 🎉` 알림이 나타났다가 자동으로 사라집니다.

현재 채점 대상은 중앙값, 계급, 도수, 상자그림의 다섯 항목, 확률 계산 `(1)`, `(2)`입니다.

### 3. 게임 탭

게임 탭에는 몬티홀 문제를 체험하는 미니게임을 넣었습니다.

#### 몬티홀 미니게임 흐름

1. 자동차 1개와 염소 2개가 숨겨진 세 문 중 하나를 고릅니다.
2. 진행자가 선택하지 않은 문 중 염소가 있는 문 하나를 엽니다.
3. 학생은 처음 선택을 `유지하기` 또는 다른 문으로 `변경하기` 중 하나를 선택합니다.
4. 결과를 확인하고 다음 게임을 진행합니다.
5. 항상 유지 전략과 항상 변경 전략의 승·패 누적 결과를 함께 관찰합니다.

#### 게임 UI

- 세 개의 문을 버튼으로 표현합니다.
- 열린 염소 문, 정답 자동차 문을 시각적으로 구분합니다.
- 유지·변경 버튼과 누적 전적 패널을 제공합니다.
- 게임 바깥의 점무늬 배경은 제거하고 흰색 배경으로 처리했습니다.

## 단일 HTML 배포 방식

`자료와-가능성-통합본.html`은 외부 파일을 참조하지 않는 독립 파일입니다.

파일 내부에 다음을 Base64 데이터로 포함했습니다.

- 중앙값·최빈값 삽화 PNG
- 수식 글꼴 파일
- 몬티홀 미니게임의 HTML, CSS, JavaScript

따라서 별도의 PNG, TTF, 게임 HTML, 데이터베이스, 웹 서버, 인터넷 연결이 필요하지 않습니다.

## 개발 메모

- 향후 빈칸을 늘릴 때는 퀴즈 탭의 원문을 이미지로 바꾸지 않고, 원문 텍스트 위에 오버레이 빈칸을 추가합니다.
- 새 퀴즈는 기존의 입력형, 도표 오버레이형, 드래그형, 객관식 오버레이형 UX 중 하나를 재사용할 수 있습니다.
- 정답 확인 로직은 `자료와-가능성-통합본.html` 내부 JavaScript에 있으며, 추가 문항을 만들 때 정답 배열만 확장하면 됩니다.
